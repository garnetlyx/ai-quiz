# Security Policy

## Supported Versions

Only the latest commit on `main` is supported with security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately via
[GitHub security advisories](https://github.com/garnetlyx/ai-quiz/security/advisories/new).
Do not open public issues describing exploitable weaknesses.

Include reproduction steps and, where possible, a proof of concept. You will
receive an acknowledgement within a few days. Please avoid public disclosure
until a fix is released.

## Scope

The application code in this repository. Third-party dependency
vulnerabilities are tracked via automated dependency alerts; reports about
upstream packages should go to their maintainers.
